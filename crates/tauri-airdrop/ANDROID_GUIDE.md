# Android 使用指南

## 📱 Android 平台已知问题

### 1. 文件发送问题

**问题**：Android 上点击"发送文件"后选择文件可能会失败，显示"发送失败"。

**原因**：Android 的文件选择器返回 `content://` URI，这是 Android 的内容提供者 URI，需要特殊处理才能访问文件内容。

**临时解决方案（推荐）**：

#### 方法 A：使用应用内置文件浏览器（推荐）
1. 将要发送的文件复制到：`/storage/emulated/0/Download/` 或 `/sdcard/Download/`
2. 在应用中记住文件的完整路径
3. 例如：`/storage/emulated/0/Download/photo.jpg`

#### 方法 B：使用文件管理器
1. 打开手机的"文件管理器"应用
2. 找到想要发送的文件
3. 长按文件 → 点击"详情"或"属性"查看文件路径
4. 复制文件路径（例如：`/storage/emulated/0/DCIM/Camera/IMG_20240101.jpg`）

### 2. 接收文件位置

接收的文件保存在：
```
/storage/emulated/0/Android/data/com.colin.tauri-airdrop/files/Downloads
```

**访问方法**：
1. 打开手机的"文件管理器"
2. 导航到：`内部存储` → `Android` → `data` → `com.colin.tauri-airdrop` → `files` → `Downloads`
3. 或直接搜索接收的文件名

### 3. 权限要求

Android 应用需要以下权限：
- ✅ 网络访问（WiFi）
- ✅ 多播网络（用于设备发现）
- ✅ 存储访问（读写文件）
- ✅ 通知权限（Android 13+）

**授予权限**：
1. 打开手机"设置" → "应用" → "tauri-airdrop"
2. 点击"权限"
3. 确保所有权限都已授予

### 4. WiFi 要求

**重要**：Android 设备必须连接到 WiFi 网络才能使用 P2P 发现功能。

- ❌ 移动数据：不支持
- ✅ WiFi：必需
- ✅ 同一局域网：所有设备必须在同一 WiFi 网络

## 🔧 故障排除

### 设备无法被发现

**检查清单**：
1. ✅ 确认 Android 设备已连接到 WiFi（不是移动数据）
2. ✅ 确认所有设备在同一 WiFi 网络
3. ✅ 检查应用是否获得了所有必需权限
4. ✅ 尝试关闭并重新打开应用
5. ✅ 检查 WiFi 路由器是否启用了 AP 隔离（某些公共 WiFi 会启用此功能）

### "发送失败"错误

**可能原因**：
1. 文件路径不正确
2. 文件无法访问（权限问题）
3. content:// URI（需要按上述方法 A 或 B 操作）

**解决方法**：
```bash
# 使用 adb 查看日志（开发者）
adb logcat | grep -i "tauri_airdrop\|daemon"
```

### "加载设备失败"

**原因**：Daemon 初始化时间较长（Android 需要获取多播锁）

**解决方法**：
1. 等待 10-15 秒后刷新设备列表
2. 检查应用是否显示"初始化中..."状态
3. 如果长时间初始化，重启应用

## 🚀 性能优化建议

1. **保持应用在前台**：Android 会限制后台应用的网络活动
2. **使用较小的文件测试**：首次使用时建议先发送小文件（< 10MB）
3. **避免锁屏**：接收文件时保持设备屏幕开启
4. **WiFi 信号强度**：确保设备离路由器不要太远
